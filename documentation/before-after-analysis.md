# Before-and-After Content Analysis

## Purpose
This qualitative comparison demonstrates how AI-assisted drafting can be improved through source-aware human editing. It is an editorial analysis, not a measured experiment or user study.

| Topic | Example weak initial wording | Source-aware revised wording | What changed |
|---|---|---|---|
| Updates | “Click update alerts to secure your device.” | “Install updates through built-in settings or official publisher channels; avoid unexpected update links.” | Adds trusted-channel guidance and addresses fake prompts. |
| Backups | “Save everything to the cloud and you are safe.” | “Keep a second recoverable copy and test restoration; understand how sync handles deletions and version history.” | Removes the guarantee and distinguishes sync from backup. |
| Permissions | “Never allow apps to access your data.” | “Grant only permissions needed for the feature and review them periodically.” | Replaces an impractical absolute with contextual least privilege. |
| Public Wi-Fi | “A VPN makes public Wi-Fi safe.” | “Confirm the network, use secure sites and understand that a VPN does not make phishing sites legitimate.” | Narrows the VPN claim and preserves layered precautions. |
| Browsing | “The padlock means the website is safe.” | “HTTPS encrypts the connection to the domain; inspect the domain because HTTPS alone does not prove legitimacy.” | Corrects the technical meaning of HTTPS. |

## Analysis
The revised versions are more useful because they:
- Replace absolute guarantees with bounded statements.
- Separate a security feature from the broader outcome users might assume it provides.
- Include a practical action.
- Preserve important caveats when content is shortened.

## Limitations
No timed baseline, blind scoring, participant study or quantitative readability test was conducted for this comparison. Do not report percentage improvements or claim measured effectiveness. If an evaluation is later performed, record the rubric, reviewers, sample size and raw results.
