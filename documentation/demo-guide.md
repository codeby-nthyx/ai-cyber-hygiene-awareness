# Live Demonstration Guide

**Suggested duration:** 4–6 minutes

## Demo sequence
1. **Introduce the problem (30 sec):** Students need short, accurate cyber-hygiene guidance.
2. **Show the research structure (45 sec):** Open the five campaign topics and explain that official sources—not model confidence—are the basis for factual claims.
3. **Show one AI prompt (45 sec):** Open the prompt library and explain its audience, output and evidence constraints.
4. **Show the before/after correction (60 sec):** Compare the HTTPS or backup example. Point out the removed absolute claim and retained caveat.
5. **Show campaign outputs (60 sec):** Open the article, social posts, quiz and Canva presentation.
6. **Run the automation (60 sec):** In a terminal at the repository root, run `python automation/generate_tip_drafts.py`; open the generated Markdown file.
7. **Close with responsible AI (30 sec):** Show the privacy rules and explain that the script drafts content but does not verify or publish it.

## Evidence to capture
- Repository page showing the project files.
- Canva presentation opened in edit/view mode.
- Terminal showing successful automation execution.
- Generated `automation/generated_posts.md` file.
- Actual AI prompts and outputs used, with personal data removed.
- Completed source verification log.

## Do not claim
- A measured improvement in awareness without a real pre/post evaluation.
- Engagement or reach without platform analytics.
- Independent tool usage without screenshots or logs.
- Verified source status before opening and checking the cited pages.
