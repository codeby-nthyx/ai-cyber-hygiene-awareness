# Cyber Hygiene Quiz

Choose one answer for each question.

## Questions

**1. What is the safest way to install an operating-system update?**  
A. Follow any pop-up that appears  
B. Use the device's built-in update settings  
C. Download it from a link in an unknown message  
D. Disable updates permanently

**2. What makes a backup useful?**  
A. It exists and can be restored  
B. It is stored only on the same device  
C. It is never checked  
D. It is the same as deleting old files

**3. Why might cloud synchronisation not be a complete backup strategy by itself?**  
A. It never uses the internet  
B. It may synchronise deletions or unwanted changes  
C. It always encrypts every file end-to-end  
D. It cannot store documents

**4. Which permission should a basic calculator app normally make you question?**  
A. None in every possible case  
B. Contacts access without a clear feature need  
C. A permission required for a feature you chose  
D. A permission you can review

**5. What should you do before joining a café's public Wi-Fi?**  
A. Choose the strongest-looking network name  
B. Confirm the correct network name with the venue  
C. Turn off all device updates  
D. Share your password with the network operator

**6. Does using a VPN guarantee that a website is legitimate?**  
A. Yes  
B. Only on public Wi-Fi  
C. No  
D. Only when the website has a logo

**7. What does HTTPS primarily indicate?**  
A. The website is approved by the government  
B. The connection to the domain is encrypted  
C. The website cannot be fraudulent  
D. The device has no malware

**8. A message says your account will close in five minutes and asks you to sign in through its link. What is the safest response?**  
A. Click quickly  
B. Reply with your password  
C. Open the official app or type the known address independently  
D. Forward it to everyone

**9. How often should app permissions be reviewed?**  
A. Periodically and when app needs change  
B. Never  
C. Only after losing a phone  
D. Only when an app requests every permission

**10. Which is the best overall cyber-hygiene approach?**  
A. Depend on one security app for everything  
B. Assume careful users cannot be attacked  
C. Combine updates, recoverable backups, limited permissions and cautious browsing  
D. Reuse one password everywhere

## Answer key with explanations
1. **B** — Built-in settings or official publisher channels reduce the risk of fake update links.
2. **A** — A backup must be recoverable; test restoration.
3. **B** — Synchronisation can replicate deletions or unwanted changes, depending on the service.
4. **B** — Permission requests should match the app's feature needs.
5. **B** — Verify the network with the venue rather than trusting a similar-looking name.
6. **C** — A VPN does not validate a website's identity or honesty.
7. **B** — HTTPS protects the connection to the named domain; it does not certify the site's legitimacy.
8. **C** — Navigate independently instead of using an unexpected sign-in link.
9. **A** — Review permissions periodically and whenever app functionality or needs change.
10. **C** — Cyber hygiene is layered; no single tool guarantees safety.

**Scoring guide:** 9–10: Strong understanding; 7–8: Review the missed topics; 0–6: Revisit the five campaign habits.

**Evaluation note:** This quiz is a learning resource, not evidence of campaign impact. Record participant numbers and scores only if a real quiz is conducted, with appropriate consent and without collecting unnecessary personal data.
